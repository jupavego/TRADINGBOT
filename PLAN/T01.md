# T01 — Cimientos: paquete, contratos, git, gate
Fase 0 · Depende: — · Esfuerzo: medio · Skills: skill-creator (opcional), update-config (opcional)

## Objetivo
Crear el esqueleto del paquete `eim/` con los contratos de datos y un gate de calidad, sin tocar `F7/`.

## Leer (solo esto)
`CLAUDE.md`, `PLAN/CONTRATOS.md`. Nada de `F7/` ni `repos/`.

## Entregables
1. `git init` en la raíz + `.gitignore` (excluir `repos/`, datos `*.parquet`, `*.duckdb`, `node_modules`, `.venv`, `__pycache__`). Primer commit.
2. `pyproject.toml` (Python ≥3.11; deps: pydantic>=2, pandas, numpy, fastapi, uvicorn, duckdb, httpx; dev: pytest, ruff, pyright). Config de ruff y pytest.
3. Árbol `eim/{core,data,agents,forecast,synthesis,risk,execution,backtest,api}/` con `__init__.py`, y `tests/`.
4. `eim/core/`: modelos pydantic de `CONTRATOS.md` (Candle, MarketSnapshot, Overlay, AgentReport, Scenario, ForecastSet, Synthesis, Mode) + protocolo `Agent`. Validaciones: 3 escenarios suman 1; sesgo en [-1,1]; velas ordenadas.
5. `tests/core/` con pruebas de validación y de serialización JSON (ida y vuelta).
6. Skill de proyecto `.claude/skills/eim-new-agent/SKILL.md`: checklist y plantilla para crear un agente (paquete, params, tests, registro).
7. Instalar en modo editable y comprobar el gate.

## Aceptación
`python -m ruff check eim tests && python -m pytest -q` pasa en limpio. `python -c "import eim.core"` funciona. Contratos idénticos a `CONTRATOS.md` (si hay que cambiar uno, actualizar el documento).

## Fuera de alcance
Lógica de agentes, datos reales, API, UI.

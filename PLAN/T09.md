# T09 — Frontend base + gráfico de velas en vivo
Fase 2 · Depende: T08 · Esfuerzo: medio · Skills: frontend-design (plugin), dataviz, run

## Objetivo
Proyecto Vite + TypeScript con la "Mesa de trading" base: layout, tema claro/oscuro y gráfico de velas en tiempo real.

## Leer (solo esto)
`CLAUDE.md`, `PLAN/UI_SPEC.md`, `PLAN/CONTRATOS.md` (solo Candle/Overlay). Requiere Node.js instalado (verificar `node -v`; si falta, detenerse y avisar).

## Entregables
1. `eim/web/` (Vite + TS, sin frameworks pesados salvo que aporten claramente). Tokens de diseño (CSS variables) claro/oscuro con interruptor.
2. Layout de `UI_SPEC.md`: barra superior (activo, marco, "En vivo", etiqueta de modo), gráfico central, columna derecha vacía con marcador de lugar, panel inferior con pestañas vacías.
3. Gráfico con Lightweight Charts: histórico por REST y actualización por WebSocket (vela en formación + cierre). Selector de activo y marco. Manejo de reconexión y estado "sin conexión".
4. Cliente tipado de la API (tipos generados o escritos a mano a partir de los contratos).

## Aceptación
Con la API corriendo: el gráfico muestra velas reales de BTCUSDT y la última vela se actualiza en vivo. Verificar con screenshot y leyendo los datos de la serie (no solo ausencia de errores). Funciona en tema claro y oscuro, y a ancho de tablet.

## Fuera de alcance
Overlays del agente, panel de agentes, escenarios.

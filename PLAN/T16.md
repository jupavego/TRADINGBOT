# T16 — Proyección: trayectorias OHLC (línea base + Kronos opcional)
Fase 4 · Depende: T03 T05 · Esfuerzo: alto · Skills: code-review (low)

## Objetivo
Generar muchas trayectorias futuras de velas OHLC (20–30 velas) desde el precio actual, con un motor base estadístico y, opcionalmente, Kronos.

## Leer (solo esto)
`CLAUDE.md`, `PLAN/CONTRATOS.md` (ForecastSet/Scenario), `PLAN/notas/T04_auditoria.md` (veredicto sobre Kronos y licencias). Referencias por grep en `repos/repo_profiles_master.md`: `statsforecast` (intervalos conformales), `limit-order-book` (Parkinson/GK).

## Entregables
1. `eim/forecast/base_engine.py`: volatilidad condicional (EWMA/GARCH ligero) + deriva parametrizable + muestreo de **formas de vela históricas** (bootstrap de cuerpo/mechas relativos al ATR) → N trayectorias (por defecto 200) de velas OHLC válidas (h≥max(o,c), l≤min(o,c)).
2. `eim/forecast/kronos_engine.py` (opcional, detrás de interruptor): cargar los pesos oficiales (según T04), muestrear 50–100 trayectorias con temperatura/top-p. Dependencias pesadas como extra opcional (`pip install .[kronos]`); si no están, el motor se omite sin error.
3. Interfaz común `Engine.sample(snapshot, horizon, n) -> array de trayectorias`.
4. Comparación mínima: pinball loss de cuantiles y cobertura de bandas sobre una ventana histórica fuera de muestra, para cada motor (script en `eim/forecast/eval.py`). Kronos solo se recomienda si supera la línea base.
5. Tests: validez de velas, reproducibilidad con semilla, horizonte 20–30.

## Aceptación
Gate pasa. Para BTCUSDT 1h, el motor base produce 200 trayectorias de 25 velas válidas en pocos segundos; el reporte de evaluación indica cobertura de las bandas del 50/80 % cercana a la nominal. Si se instala Kronos, mismo contrato de salida.

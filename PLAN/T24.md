# T24 — Agente de contexto (LLM)
Fase 5 · Depende: T05 · Esfuerzo: medio · Skills: claude-api

## Objetivo
Un agente que lee noticias/sentimiento y devuelve contexto estructurado (el calendario económico lo cubre el agente determinista `calendar`, T36; este agente puede leer su salida). **Solo informa; nunca ejecuta ni fija tamaño.**

## Leer (solo esto)
`CLAUDE.md`, `PLAN/CONTRATOS.md` (AgentReport). Por grep: `repos/repo_profiles_master.md` → FinGPT/FinRobot (patrón de prompt narrativo).

## Entregables
1. `eim/agents/context/`: la lectura de fuentes vive en `eim/data/providers/news.py` (I/O); el agente recibe titulares ya cargados en el snapshot. Salida estructurada validada por pydantic: `{tema, sentimiento −1..1, catalizadores[], riesgo_evento: bajo|medio|alto, fuentes[]}`.
2. Uso de la API de Claude con caché de prompt, salida estructurada y límite de coste por ciclo; temperatura baja; cada afirmación cita su fuente (sin fuente = descartada).
3. Defensa ante inyección de instrucciones en titulares: el texto externo se trata siempre como datos; prueba con un titular malicioso.
4. Degradación: sin clave/sin red → `status="no_data"`. El resultado puede reducir confianza o activar una pausa por evento, nunca abrir operaciones.

## Aceptación
Gate pasa con LLM simulado en tests; ejecución manual con clave real produce JSON válido con fuentes; el test de inyección pasa.

## Fuera de alcance
Debate multiagente completo; trading por noticias.
